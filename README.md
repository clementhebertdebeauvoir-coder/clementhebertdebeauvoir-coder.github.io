# Blog personnel de Clément Hebert de Beauvoir

Site statique publié sur GitHub Pages à l'adresse:
https://clementhebertdebeauvoir-coder.github.io

## Structure

- index.html : page d'accueil, liste des articles
- style.css : feuille de style du site
- posts/ : un fichier HTML par article

## Publier un article

1. Dupliquer un fichier dans posts/ (bienvenue.html est le modèle le plus simple)
2. Modifier titre, date, contenu
3. Ajouter le lien dans la liste de index.html
4. Commit et push: GitHub Pages republie automatiquement en une à deux minutes

## Travailler en local

git clone https://github.com/clementhebertdebeauvoir-coder/clementhebertdebeauvoir-coder.github.io
# modifier les fichiers, puis:
git add .
git commit -m "Nouvel article"
git push
