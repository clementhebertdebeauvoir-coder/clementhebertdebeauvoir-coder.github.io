Bienvenue

20 novembre 2026

Ce site est mon carnet personnel. J'y mets ce que je veux y mettre : des notes sur la finance d'entreprise, des essais d'automatisation avec Google Apps Script, de la veille sectorielle, et des bricolages web.

Pourquoi un site à soi

Les plateformes modifient leurs règles, ferment, ou enterrent vos textes sous des algorithmes. Un site statique sur un dépôt GitHub, c'est l'inverse : quelques fichiers texte, une adresse, rien d'autre. Tant que le dépôt existe, le site existe.

Comment ce site a été construit

De zéro, en une soirée, avec l'aide de Vibe, l'assistant de Mistral AI : HTML et CSS écrits à la main, sans framework, sans base de données, sans dépendance. Le code source est public dans le dépôt GitHub du site et l'hébergement est assuré par GitHub Pages. Coût total : zéro euro.
